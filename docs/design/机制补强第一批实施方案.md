## 一、① 样本量对比告警（机制补强 1.2，成本低/价值高，防御性）

**目的**：防"采集量骤降被误判为能力衰退"。Z-score 信号在证据量不足时会失真——这是"动态演化"最易被评审攻击的造假点；主动告警是防御性设计（08-19 曾实况：Clash 关闭致全源探活失败，若落进演化窗口即会误判）。

**改动**（全部在既有路径）：
| # | 文件 | 改动 |
|---|------|------|
| 1 | `graph_version.py::create_snapshot` | 创建快照时对比新旧窗口证据量（jd 数 / REQUIRES 边数 / 独立源数） |
| 2 | `models/business.py::GraphVersion` + Alembic | 增 `data_warning` JSONB（涉及范围 + 具体数字）；已有 `snapshot_json` 可复用 |
| 3 | `api/v1/evolution.py` `/evolution/versions` | 透出 `data_warning` |
| 4 | 前端演化页 | 渲染"采集量下降，趋势可能失真"徽章（机制补强 4.1 freshness badge 顺带） |

**判定规则（候选，D2 确认阈值）**：新 < 旧×**50%** 或 > 旧×**200%** → 记录 data_warning；更严格档 30%/150%。

**验收**：构造证据量减半的用例 → 快照带 data_warning；前端徽章可见；既有快照无告警不回归；单测覆盖阈值边界。

## 二、② 谱系事件扩展 born / merged / ended（机制补强 1.1，成本低/价值高）

**目的**：赛题核心"动态演化"的可展示事实从 2 类（rename/split）扩到 5 类——born（涌现）/ merged（归并）/ ended（消亡）是"岗位诞生与消失"的直接证据，答辩叙事价值高。

**现状（已核实 `evolved_from.py::derive_evolved_from`）**：基于相邻快照 Position 集合差 `new_names = cur - prev` / `gone_names = prev - cur`；现按 `_name_containment`（rename）与 `_shared_segments`（split）配对，**未配对的 new/gone 直接跳过（+skipped）**——born/ended 信号其实已在候选里、只是没落库。

**改动**：
| # | 文件 | 改动 |
|---|------|------|
| 1 | `evolved_from.py` | 配对逻辑扩展：`merged`（一个 new 同时包含多个 old，现 `_name_containment` 对多 old 命中即此）；`born`（new_names 未配对任何 old）；`ended`（gone_names 未配对任何 new）。**宁缺毋滥**：born 判定须排除已 ren/split/merged 配对的 new；ended 与 ① 告警联动（防采集停摆被误报"消亡"，见 D4） |
| 2 | `models/business.py` + Alembic | 新建 `evolution_events`（version_id / event_type / from_name / to_name / detail JSONB），Neo4j `EVOLVED_FROM` 边不变（事件为 PG 侧可展示事实） |
| 3 | `api/v1/evolution.py` | 新端点 `GET /evolution/events`（按 version 查询） |
| 4 | 前端演化页 | 事件流视图（born/merged/ended/rename/split 横条） |

**验收**：单测覆盖 born/merged/ended/paired 四类边界；对真实历史快照回放产出事件数合理（防误报需人工抽查阈值）。

## 三、成本与优先级

| 项 | 价值 | 成本 | 次序 |
|---|---|------|------|
| ① 样本量告警 | 高（防"采集波动被误判为能力变化"的防御点，评审攻击面） | 低 | **先做** |
| ② 谱系事件 | 高（born/ended 是"岗位涌现/消亡"答辩叙事） | 低~中 | 次做 |

**不做**（明确保留）：岗位级版本表、双库事务性同步层、图谱投影物化（成本高/收益低，机制补强分析已列）。

## 四、风险

- ① 的阈值过严会刷告警、过松失去意义——D2 需张恺天定档。
- ② 的 ended 判定可能把"采集停摆"误报为"岗位消亡"——**正是 ① 告警要兜底的场景**，两项一起上形成闭环（D4）。
- 全为 PG/API/前端增量改动，无模型语义变更；Alembic 迁移标注在 PR（权限收归后端+算法负责人）。
