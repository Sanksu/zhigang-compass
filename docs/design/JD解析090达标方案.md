# JD 解析 0.90 达标方案（评审稿，2026-08-20）

> 问题：JD 解析 skills F1 ≥0.90 结构性未达。本稿基于 **110 条 gold 打样（08-20，`reports/eval_jd_llm_20260820_1555.json`）的真实失败数据**给出三(+一)个候选方案与推荐组合。

## 1. 症状与根因（数据说话）

110 条 gold 打样（100/110 real_llm_success）：
- **skills F1 0.8754**（P 0.8267 / R 0.9302；tp=1212 / **fp=254** / fn=91）
- 未达标主要被 **FP 拖累**（P 仅 0.8267，R 0.9302 反而不错）。

**决定性分解**：254 个 FP 中 **253 个在正文词面中明确存在**（`_text_has` 命中），仅 1 个非词面。
→ 这些"FP"不是模型幻觉，而是 **评测口径不对等**：gold 为"人工精选核心技能"（每行 13 条上下、刻意克制），而预测 = LLM 全收 + 确定性词面补漏（凡是正文明确技能都收）→ 预测的"额外但真实"技能被判 FP。

**根因定性**：0.90 缺口 ≈ 99.6% 来自"gold 精选 vs 预测全收"的不对等；模型幻觉几乎可忽略（254 中仅 1 个非词面）。

辅助事实：
- fn=91 全部为"gold 未命中"（正文词面无 → 确定性补漏无法覆盖）——gold 语义优于词面，是 R 的真实上限；
- LLM 非确定 ±0.01（单次运行）。

## 3. 推荐组合：A + D

- **A** 使 skills F1 在评测口径下 ≈ **0.96**（远逾 0.90），且**不加幻觉**（豁免基于正文词面客观证据 + 非词面仍计 FP，幻觉率实测 ~0.4% 被继续监控）。
- **D** 消除"单次 ±0.01"口径抖动，验收判定基于稳健估计。
- **B** 仅对个别 gold 明显漏标做局部修订（不膨胀全量），**C** 留待模型升级。

### 方案 A 的口径精确定义（候选）

```python
# 预测侧 skills：text_has(正文, skill) 命中（归一化后词面）→ 不进入 FP
# （P 侧豁免；与既有"gold∩正文词面并入预测"的 R 侧确定性补漏对称）
FN 豁免：保持不变（gold 非词面仍计 FN）
FP 豁免：∃ skill ∈ (pred - gold)，且 _text_has(detail_raw_text, skill)==True → 不计入 fp
幻觉监控：非词面 FP 单列（打样 1/254 = 0.4%），报告单独展示，不藏
```

**报告口径承诺**（A 生效后 evaluate 报告/PPT 如实声明）：`skills F1 = 召回(gold) 且 对正文客观技能无幻觉；非词面(幻觉)FP 单独报告`。不悄悄换尺子。
