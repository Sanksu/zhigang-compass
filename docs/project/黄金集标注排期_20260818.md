## 二、标注口径（沿用盲审定稿规则，见 `data/golden_set/review/README.md` + `blind_review_round2_checklist.md`）

1. **title**：招聘标题优先正文语义；细分保留（React前端工程师 不泛化为 前端开发工程师）；级别不保留（高级前端工程师 → 前端工程师）
2. **skills**：必备 = 正文明确要求；bonus = 加分/优先；技术栈细化前缀保留（Vue/React/Golang/SLAM 等）
3. **experience/education**：正文为准（source 字段仅参考）；冲突以正文判断
4. **core_duties**：2-4 条精炼职责（正文职责段归纳）
5. 无法判定时填 `review_status=review_required` + `review_note` 说明，不猜测
