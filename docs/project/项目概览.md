# 智岗罗盘

> 多源异构驱动的岗位能力动态演化与人岗匹配系统
> 项目编号：XH-202621 · 科大讯飞挑战杯揭榜挂帅

一套**可追溯、可验证、可动态更新**的「人才能力大脑」，以证据节点为核心，通过多源异构数据驱动岗位能力图谱构建、动态演化与人岗精准匹配。

---

## 项目亮点

- **多源异构数据底座**：13 源 = 国内招聘平台（BOSS/智联/脉脉）+ 国际平台（LinkedIn/Indeed/Monster/Glassdoor）+ 技术社区（GitHub/SO）+ 学术论文（arXiv）+ 国内外课程平台（中国大学MOOC/Coursera/edX）+ O*NET，国内单 IP 直连 + 国际走代理池，A/B/C 三级分级管理
- **动态演化算法**：90 天滑动窗口追踪技能频次变化，六状态机（candidate → emerging → stable → declining → archived，含 rejected）管理岗位全生命周期
- **混合匹配引擎**：基于内容的多维加权匹配为主干 + Sentence-BERT 语义增强 + 规则/LLM 兜底
- **幻觉防控三道防线**：JSON Schema 强校验 + 跨源交叉验证 + 规则白名单后过滤
- **图谱可视化**：2D 力导向图（ECharts）为主，3D 模式（react-force-graph-3d/WebGL）可选增强，2D 模式 ≥ 100 节点 @ 60fps

## 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | Vite 6 + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui + Zustand + TanStack Query v5 |
| 图谱可视化 | ECharts（默认 2D）+ react-force-graph-3d（可选 3D） |
| 后端 | FastAPI + Pydantic + SQLAlchemy 2.0 (async) + Alembic |
| 数据库 | PostgreSQL 15（pgvector 扩展 + JSONB 快照存储） + Redis 7 |
| 图谱 | Neo4j 5 + Cypher + GDS + Full-Text Index（中文搜索） |
| 大模型 | OpenAI 兼容 API（讯飞星火 / Qwen / GPT / DeepSeek 等，provider 可切换） |
| 数据管线 | Scrapy + Playwright + ARQ（任务队列）+ SimHash/MinHash |
| 容器化 | Docker + Docker Compose (5 服务，FastAPI 托管前端) |
| 测试 | PyTest + Vitest + Playwright + Locust |

## 快速启动

### 环境要求

- Node.js ≥ 20.10 + pnpm 9
- Python ≥ 3.11 + uv (推荐) / pip
- Docker Desktop ≥ 24.0 + Docker Compose v2
- Neo4j 5.x / PostgreSQL 15 / Redis 7（可由 Docker Compose 启动）

### 一键启动（规划）

```bash
# 1. 克隆仓库
git clone <repo-url>
cd zhigang

# 2. 启动基础设施（Neo4j/PG+pgvector/Redis）
docker compose up -d

# 3. 启动后端
cd backend && uv sync && uv run uvicorn app.main:app --reload

# 4. 启动前端
cd frontend && pnpm install && pnpm dev
```

### 环境变量

复制 `.env.example`（待添加）为 `.env`，配置以下关键变量：

```bash
# 大模型（OpenAI 兼容 API，可切换 provider）
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=your_key_here
LLM_MODEL=deepseek-v4-flash

# 数据库
POSTGRES_DSN=postgresql+asyncpg://user:pass@localhost:5432/zhigang
NEO4J_URI=bolt://localhost:7687
REDIS_URL=redis://localhost:6379/0
```
