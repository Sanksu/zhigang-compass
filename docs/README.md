## 文档版本约定

- **设计文档.md**：系统设计单一事实源，变更须经 PR + 算法/后端负责人 Review
- **执行计划.md**：分阶段任务与时间节点，变更须经项目负责人确认
- **进度跟踪.md**：基于源码审计的进度快照，每阶段结束时更新
- **Code-Wiki.md**：随代码演进同步更新，反映当前主分支状态
- **reviews/**：时点性审查/治理报告，只增不改（结论被后续推翻时以新报告为准）
- **postmortems/**：事故复盘与规则沉淀，新条目按编号递增并登记本索引
