# 答辩演示：4D 图谱与演化叙事话术（2026-08-22）

> 配套本分支功能：演化信号抗波动补强（PR-1）、桑基图 + 时间轴播放（PR-3）、
> 技能衰退预警 C 端引导（PR-4）。供答辩演示脚本/PPT 引用。

## 一、4D 图谱：Git 式时间维度（对应评估建议 1）

**一句话话术**：

> "我们的知识图谱不是静态快照，而是具有时间维度的 **4D 图谱**。系统每日 05:00
> 自动发布一个全量版本（`graph_v20260822`，Commit 式版本号），就像 Git 一样，
> 任何一个历史时刻的人才市场状况都可以通过版本 ID 精确回溯。"

**支撑证据（评委可现场验证）**：

| 能力 | 入口 | 说明 |
|------|------|------|
| 版本提交历史 | 演化看板 → 版本对比（版本下拉） | 每日版本含节点/边增删统计与变更摘要 |
| 任意两版本 Diff | 版本对比 → 选择 from/to | 节点级新增/删除/变化 + 边级增删 |
| 数据可信性防线 | 版本列表 data_warning 列 + 信号黄标 | 证据量萎缩 <50%/膨胀 >200% 自动告警 |
| 90 天保留策略 | 设计文档 §7.1 | 自动清理，成本可控 |

**答辩 Q&A 备用**：

- Q: 怎么保证趋势不是爬虫波动造成的？
  A: 三层防线——① 版本级样本量对比告警（50%/200% 阈值，可视化横幅+信号黄标）；
  ② 信号输出同时给出**占比口径**（freq_ratio：该技能频次/当期 REQUIRES 总边数），
  剔除总量因素后判断；③ 观察池侧平台健康守卫（平台周抓取量 < 基线中位数 50%
  的故障周样本自动剔除出信号基线）。Z-score 判定本身的占比化改造已在
  feature/algo-evolution-normalized-zscore 分支完成，待算法负责人确认合入。

## 二、演化故事线演示剧本（对应评估"答辩核心剧本"）

按演化看板页面自上而下演示（约 90 秒）：

1. **感知涌现**：顶部「技能衰退预警」卡 → 说明系统不仅追踪新兴技能
   （观察池 MLI 产业化拐点），也向 C 端求职者直白提示"哪些技能需求在衰退"。
2. **Z-score 信号**：新兴/衰退 Top-10 表格 → 指着"占比口径"列讲归一化，
   指着黄标讲证据量异常打标（打标不剔除，可信 AI）。
3. **岗位演化 + 时间轴播放**：岗位演化历史卡片 → 点击「播放」按钮，
   折线图滑窗自动回放该岗位关联技能边数的演进（答辩动态感关键帧）。
4. **技能 → 岗位变迁桑基图**：在下拉中选择一个技能（如 Vue.js / Python）→
   桑基图展示各期 Top-8 关联岗位的进出与持续需求厚度——
   "输入一个技能，看它服务的岗位群体如何变迁"。
5. **版本 Diff（4D 收尾）**：版本对比选两个日期 → "这就是 Git 式回溯，
   任意历史时刻的人才市场状况都可以 diff 出来。"
6. **图谱页联动**（可选加分）：图谱中点开一个衰退预警技能节点 →
   节点详情面板显示橙色「需求衰退预警」徽标 + 学习路径替代建议——
   "预警不只给管理者看，更直接引导每一位求职者"。

## 三、系统架构叙事（对应评估"故事线三幕"）

- 侦测雷达：`watch_signal_daily`（每日）+ `graph_versions` 快照（每日 05:00 T+1）；
- 溯源演化网络：`derive_evolved_from` 推导 EVOLVED_FROM 谱系（born/merged/ended
  事件落 `evolution_events`，演化看板「谱系事件流」可见）；
- 专家自愈环：突变经管理后台演化审核 Tab 人工确认后正式生成新岗位画像，
  学习路径 gap 建议随之更新（图谱节点详情 → 学习路径闭环）。
