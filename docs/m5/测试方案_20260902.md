## 5. 准确率评测方案与结果

### 5.1 方法学

- **双口径**：raw（字面匹配）与 aligned（词面真值对齐，PR #330 批准 + #488 别名感知豁免）并列计算归档；raw 误差主要来自大小写/单复数/缩写等词面差异。
- **快照口径**：`EVAL_SPEC_VERSION = "20260824-a"`（prompt/schema/规则链联合快照标识，跨轮可比）。
- **三跑验收**：正式验收三轮独立运行，极差为 0。
- **「准确率」判定口径**：人岗匹配项即 Accuracy；抽取项为字段级 F1——系逐字段准确率的**更严口径**（JD aligned precision=1.0000 零假阳性、recall 0.9290）。

### 5.2 三项准确率结果（对外主口径）

| 能力 | 金标 | 结果 | 产物 | 复现命令 |
|------|------|------|------|---------|
| JD 解析 | 110 条 | **aligned F1 0.9632**（raw 0.8865 保守口径；precision 1.0000 / 幻觉 FP=0 / 零 fallback） | `backend/reports/eval_jd_llm_20260828_*.json` ×3 | `python tests/evaluate/run_manual_jd_eval.py --gold-jsonl data/golden_set/final/jd_golden_110.jsonl --run` |
| 简历抽取 | 50 条合成集（赛题未规定简历集条数；构造说辞见赛题自检评估报告附注①） | **F1 0.988** | `backend/reports/eval_*.json` | `python scripts/evaluate.py --task resume` |
| 人岗匹配 | 384 对（v3 金标含学历维度） | **Acc 0.9714** / Spearman 0.7853（BT v4；历史演进 v2 0.8906 → v4 0.9714） | 黄金集 `golden_set_match_v3.jsonl` | `python scripts/tune_match_weights_fourdim.py` |

**三项均 ≥90%（aligned/Accuracy 口径）✅✅✅**。

## 6. 测试环境与门禁

| 环境 | 内容 | 门禁 |
|------|------|------|
| 本地 | `uv run pytest`（integration 默认 deselect；离线环境 `HF_HUB_OFFLINE=1` 防 SBERT 联网下载挂起）；`pnpm test` / `pnpm e2e` | 开发者自测 |

| CI（nightly） | `ci-integration-nightly.yml`：integration 标记用例专项跑 | 每日回归 |
| 线上验证 | 226 局域网部署 5 容器健康检查 + 每日 T+1 ETL 产出验证（freshness/diversity 日报） | 运行时监控 |

## 8. 迁移性（技术方案推广验证）

技术方案的领域无关层（本体模型 / SimHash 清洗 / SBERT 归一 / BT 匹配引擎 / Z-score 发现 / RAG 接地 / 任务化评测框架）与领域配置层（采集源清单 / 技能白名单 / Prompt Few-Shot / 种子词表）边界清晰，迁移至低空经济、智能网联汽车、生物制造等新一代信息技术延伸领域**预计 1-2 周**（八维×迁移成本表见设计文档 §17.2）。评测框架（`evaluate.py --task`）对任务类型通用，新领域仅需重标金标与重建白名单。
