## 第 1 页 · 封面
- **智岗罗盘——多源异构驱动的岗位能力动态演化与人岗匹配系统**
- 科大讯飞挑战杯·揭榜挂帅 | 项目编号 XH-202621 | 2026.07.13—09.05

## 第 2 页 · 项目背景与行业痛点
- 技术迭代速度远超人才培养周期：AI/大模型每季度新方向 vs 4 年本科
- 结构性供需错配：企业"招不到合适的人"，求职者"不知道学什么"
- 招聘 JD 三大问题：**时滞**（沿用 3 年前要求）、**抄袭**（同质化）、**通胀**（虚高要求）
- 传统人岗匹配停留在关键词命中，缺技能级差距诊断与个性化学习路径

## 第 3 页 · 核心创新点（3+1）
1. **动态演化**：从"静态画像"到"动态感知"——岗位能力图谱随技术趋势自我进化
2. **多源交叉验证**：JD × 课程 × 论文/社区 × 国家职业分类四源融合
3. **技能级人岗匹配**：三维评分 + 差距诊断 + 个性化学习路径
4. **幻觉防控三道防线**：Schema 强校验 / 词典过滤 / 证据链可追溯

## 第 4 页 · 系统总体架构
- 五服务容器化：api / postgres(pgvector) / redis / neo4j / worker(ARQ)
- 数据栈：PostgreSQL 15 + pgvector（向量）+ Neo4j 5（图 + cjk 全文索引）+ Redis 7
- 三层：数据采集层 → 图谱/算法层 → API/前端层
- FastAPI 同端口托管前端，中间件承担 CORS/CSP/HSTS/限流

## 第 5 页 · 数据采集与治理（13 源三级）
- 13 数据源 A/B/C 三级分级（BOSS 直聘 08-15 起暂停采集 / 智联/脉脉 + Coursera/edX + arXiv/GitHub/SO）
- 国内直连 + 国际代理池三梯队（随机轮换/失败剔除/直连兜底）
- 清洗管线：长度过滤 → 质量评分 → SimHash 去重 → 时效加权
- 合规：robots.txt + 请求间隔 + 官方 API 条款背书

## 第 6 页 · 知识图谱构建（Neo4j）
- 实体：Position / Skill / Course / Evidence / Occupation（国家职业分类 1639+）
- 关系：REQUIRES（权重+必要性）/ LEARNABLE_VIA / EVOLVED_FROM
- 岗位名归一化：技术栈细分保留（React前端工程师）+ 失真兜底族技能路由
- cjk 全文索引替代 Elasticsearch（中文检索零额外服务）

## 第 7 页 · LLM 抽取与幻觉防控
- 分层 Prompt：System / Task / Few-Shot 三层
- 多 provider 重试链（OpenAI 兼容，deepseek 当前在线）
- **三道防线**：Pydantic Schema 强校验 → 白名单/停用词词典过滤 → 证据链可追溯
- ⚠️ 演示话术（08-21 H5 裁决 B）：跨源交叉验证表述为「**每日计算并展示一致性**（看板可见），硬门控列入路线图」——**不宣称「单源不入图已拦截」**，评委追问时如实回答口径
- 评测闭环：**110 条正式黄金集**（Round1 人工标注交付）LLM 盲审——技能 aligned F1 **0.9629**（词面真值对齐口径，目标 ≥0.90 达标；raw 0.8825；幻觉 FP 率 <1%）

## 第 8 页 · 人岗匹配引擎
- 三维评分：技能匹配（must/nice 加权）+ 经验 + 学历
- 语义增强：SBERT 多语言模型 + Bradley-Terry 权重学习（Spearman 0.88）
- 通胀修正（CII）+ 时效衰减 + 跨域降权
- 批量推荐 + 单点比对（BS）双模式

## 第 9 页 · 演化发现（岗位生命周期）

- 状态机：emerging → stable → declining（置信度阈值 + RAG 接地）
- 技术热点观察池（arXiv/GitHub）→ 自动升级 candidate
- 媒介落差指数 MLI：四维信号综合判定产业拐点
