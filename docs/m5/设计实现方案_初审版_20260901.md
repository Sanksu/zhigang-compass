## 0. 一句话

基于 **PostgreSQL(pgvector) + Neo4j + Redis + ARQ** 多源异构数据底座，实现「岗位能力动态演化 + 人岗匹配」系统：13 源采集 → LLM 抽取归一 → 图谱演化建模 → 五维匹配 + 学习路径。**关键创新**在三条：①岗位职能域治理（骨干域+归类制，可解释性满分级）②BT 四维权重匹配（education 进评分，Acc 0.9714）③多源证据可溯源（每技能可追到原始 JD）。

## 1. 系统架构与数据流

```
13源爬虫(Scrapy/Playwright/代理池) → jd_raw(PG JSONB) → LLM抽取(Pydantic强校验)
  → 技能归一(词典/动态别名/SBERT) → Neo4j图谱(Position:REQUIRES→Skill:EVOLVED_FROM)
  → 演化检测(PageRank/Louvain/Leiden) → 人岗匹配(SBERT+BT权重) → 学习路径(RAG+课程池)
```

分三层（详见 `Code-Wiki.md`）：
- **采集层**：13 源 A/B/C 三级，国内直连 + 国际代理池（ProxyPoolMiddleware 随机轮换）
- **治理层**：LLM 驱动灰度（六域决策信封 + proposal/审批/回写），岗位名/技能名双归一
- **服务层**：FastAPI + ARQ worker，`/api/v1` 契约驱动（openapi.yaml 单一事实源）

## 2. 关键机制与实现验证

### 2.1 岗位职能域治理（本周期核心）

**问题**：岗位投影图 Leiden 全量聚类暴露 4 类问题——垃圾岗污染、2 人微簇噪声、高频桥梁岗语义缺失、无人工验收口径。

**实现**（骨干域 + 归类制，替代全员聚类）：
```
① 骨干层：freq≥3 岗进 Leiden 聚类（Ω门频探针实证，≥10 会切掉前端细分族）
② 归类层：freq<3/降级岗带弃权归类（连接强度≥3.0 且领先次优1.3×才归入）
③ 可解释性：逐岗落 domain_source/score/alternative + LLM 成员自审
```

**验证**：共成员关系基准 69 条（锚点=高频稳定岗，与 LLM 域名解耦）：
| 指标 | 治理前 | 治理后 |
|---|---|---|
| 严格通过率 | 55.6% | **100%**（72/72） |
| pairwise F1 | 0.552 | 0.791 |
| 域结构 | 15 碎域(4 污染) | 5 语义域+弃权池 |
| 垃圾岗 | 30 | 0 |

**决策留痕**：全部关键决策（门频/门槛/GENERAL_PIN/簇级归类否决/弱锚定复核）在 `岗位职能域治理设计_20260901.md`，每条带回退点。LLM 自审实证 flag 3 条全为真问题。

### 2.2 人岗匹配（BT 四维权重重调）

**问题**：三维加权（must/nice/exp）在金标上 Acc 0.8906，且 exp 恒满分（字段错位）、education 仅雷达展示。

**实现**：
```
① 修复三处 JD 画像字段错位（experience_range→required_years / education.level→required_education / 词表补初中）
② education 进评分（w_edu=0.15 凸组合，education_semantics_v1 契约冻结防回归）
③ BT 四维重调：v3 金标 384 对（岗位学历要求回填 jd_golden_100，候选人学历梯度探针）
```

**验证**：
|配置|Acc|Spearman|
|---|---|---|
|基线三维|0.9141|0.7407|
|**BT v4 (w_edu=0.15)**|**0.9714**|0.7853|

**向后兼容**：v2 金标（无学历字段）在 w_edu=0.15 下 0.9141/0.7407 与 v3 逐位一致——旧数据零行为变更。判定线 0.57（Acc 验收口径）。

### 2.3 多源证据可溯源

每个技能断言可追到原始 JD（`evidence_refs`：skill → source/source_url）；匹配详情展示**最佳匹配 JD 原文**（含 "同岗 N 条 JD 中最佳" 溯源）。三层可信设计：schema 强校验（幻觉防线）、健康探针、证据引用。

### 2.4 幻觉防控三道防线

① Pydantic Schema 强校验（LLM 输出必须符合结构）② 技能/岗位名双归一（词典+白名单拦截）③ 证据引用（未被证据支持的断言不进图）。

## 3. 性能与可靠性

- panorama/search P95 430/390ms @100 并发（`perf_baseline_20260815.md`）
- 故障降级：图谱不可达→空视图、SBERT 不可用→纯规则、LLM provider 链自动切换
- 部署：5 服务 Docker Compose，健康检查 + fail-fast（生产强校验 SECRET_KEY）
