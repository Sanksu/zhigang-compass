## 五、运行时容器冒烟清单（需 Docker 环境执行）

> 此沙箱无 Docker，以下为团队在有 Docker 的机器执行的冒烟清单。

```bash
# 1. 解包
tar -xzf zhigang-compass-7e18d318.tar.gz -d zhigang-compass
cd zhigang-compass

# 2. 准备配置（参照 DEPLOY.md）
cp backend/.env.example backend/.env
# 编辑 .env：SECRET_KEY（≥32 字符）、ADMIN_PASSWORD（非默认）
# 生成 JWT 密钥：openssl genrsa -out backend/keys/private.pem 2048 && openssl rsa -in backend/keys/private.pem -pubout -out backend/keys/public.pem
# 创建运行时配置文件（从 example 复制）：
cp backend/configs/llm_providers.yaml.example backend/configs/llm_providers.yaml
cp backend/configs/runtime_settings.json.example backend/configs/runtime_settings.json
cp backend/configs/skill_filters_dynamic.json.example backend/configs/skill_filters_dynamic.json

# 3. 构建前端
cd frontend && pnpm install && pnpm build && cd ..

# 4. 启动 5 服务
docker compose up -d --build

# 5. 等待健康检查全绿
docker compose ps  # 所有服务 STATUS = healthy

# 6. 冒烟端点
curl -s http://localhost:8000/health       # {"status":"ok"}
curl -s http://localhost:8000/api/v1/graph/view/panorama  # 全景图节点
curl -s http://localhost:8000/docs          # Swagger 文档（仅 dev）

# 7. Neo4j 初始化（首次）
docker compose exec api python scripts/init_neo4j.py

# 8. 停止
docker compose down
```
