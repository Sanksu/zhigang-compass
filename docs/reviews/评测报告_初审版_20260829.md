## 二、方法学与批准记录

### 2.1 JD 解析

- **黄金集**：110 条 Round1 人工标注（A01 单标注员 + QA 复核），覆盖 12 个岗位类型、Boss + 智联双数据源
- **词面豁免**：同义/别名/大小写/单复数/连字符差异不计为错（PR #330 批准，#488 扩展别名感知）
- **三跑稳定性**：08-28 正式验收三跑 aligned F1 完全一致（0.9632），极差 = 0，稳健度高于历次
- **幻觉防控**：precision = 1.0000，非词面幻觉 FP = 0/0/0（三跑均零假阳性）

### 2.2 人岗匹配

- **v2 黄金对**：384 对 Bradley-Terry 构造（#266 + #269），标注来源：专家排序 + 一致性校验
- **方案 A**：匹配主链路统一 JD 级粒度（#589 + #597/#598/#601），08-28 重验与基线逐位一致
- **权重构成**：w_must=0.493 / w_nice=0.108 / w_exp=0.398 / sim=0.898（BT 迭代收敛结果）

### 2.3 学习路径

- **评测集**：30 案例覆盖前端/后端/算法/数据/测试/运维 6 大方向
- **评审方式**：专家定稿（张恺天），维度：先修链合理性 / 课程语义匹配 / 学时估算 / 整体合理性
- **最终结果**：29/30 通过（96.7%），远超 80% 目标
- **关键改进**：先修字典键名 `canonical_skill_name` 归一（prerequisite 0.77→0.92）+ 课程语义匹配治理（course 0.503→0.879）+ 学时分层（hours 0.42→0.916）
