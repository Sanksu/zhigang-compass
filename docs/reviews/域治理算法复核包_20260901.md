## 二、复核项

### 复核项 1：骨干门频 freq≥3（#709）

**变更**：进入骨干 Leiden 的岗位门槛由「全员」改为 freq≥3。
**依据**：探针实证 freq≥10 会把前端技术栈细分族（React/Vue/移动前端，freq 2-6）切进归类池，前端枢纽因失去族群而孤立降级——**族群质量是域凝聚力的来源**。
**请拍板**：门频取值 3 是否认可（备选 5/10 均实测更差）。

### 复核项 2：归类双门槛（亲和度 ≥3.0 + 主导性 1.3×）

**变更**：待归类岗归入最优域需同时满足 Σ亲和度 ≥3.0（≈2 条 must 共享或 1 must+7 nice）且最优 ≥ 次优 ×1.3。
**依据**：门槛 2.0 实证被 nice 共享堆砌穿透（7×0.3=2.1，弃权行准确率仅 63%）；提至 3.0 后弃权行准确率升至 63%→93%。
**请拍板**：双门槛数值与「两道门槛都过才归类」的口径（CLI 旋钮可调，无需改码）。

### 复核项 3：GENERAL_PIN 强制弃权语义（7 岗）

**变更**：产品经理/创始工程师/SAP集成/Murex应用/AI与数据系统/生化工程师/CMBS交易员 强制弃权落通用域。
**依据**：share 探针实证其连接证据无差别指向枢纽域（与正例分布完全重叠），纯拓扑不可分；多为停用词存量待衰减节点。
**请拍板**：弃权语义是否认可；CMBS交易员（现误挂数据分析域）是否同意弃权。

### 复核项 5：测试域归属口径（阻塞 100% 的最后一步）

**现状**：测试工程师(122) 为桥接岗无固定语义域，经归类门槛自然落入后端开发域；生物信息学 QA 依基准断言随其后。基准唯一未满分原因即此断言链。
**请拍板**：①接受"测试族暂归后端域，测试域成型后随迁"（当前实现）；②或立项独立测试域（测试工程师 122 + 生物 QA 1，成员不足 3，需等数据）。

### 复核项 6：方案②簇级归类否决留痕（未实施，供评审）

两轮探针实证否决"微簇池化亲和度"与"人均亲和度"两版簇级归类：**2/14 与 11/26，负例分数高于正例、分布完全重叠**。结论：薄画像岗的连边证据不携带域语义，拓扑不可分。剩余演进方向 = 嵌入 kNN 图（P3，需先转正基准集；注意 MiniLM 中文技能词跨域虚高前科）。
**请拍板**：确认否决结论归档、嵌入方案作为赛后方向。

### 复核项 7：LLM 成员自审 prompt 口径（#711）

**机制**：每次域同步后一次批量 LLM 调用逐域裁决内聚性，可疑成员落 `cluster_membership` proposal/R2 进审批页（只检测不改写；批准=确认在案，驳回=误报关单）。**本机实证**：自动 flag 3 条全部为真问题（芯片族混入算法域 / 数据分析的 CMBS / 后端的测试·网络桥接岗）。
**判定原则**：从严——宁可漏报不可误报。
**请拍板**：prompt 判定口径与"只检测不自动改写"边界。
