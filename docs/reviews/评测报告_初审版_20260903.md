## 二、方法学与批准记录

### 2.1 词面豁免口径（PR #330）

JD 技能抽取评测中，系统抽取的技能名与 gold 标注在词面不同但语义等价时（如「Python3」vs「Python」、「React.js」vs「React」），经 `PositionAligner`（Neo4j 图谱别名 + SBERT 语义相似度）对齐后视为命中。此口径经 PR #330 评审批准，**对外双口径并列**：raw F1 0.8731 / aligned F1 0.9629。

### 2.2 BT 四维权重匹配（v4，2026-09-01）

匹配引擎采用 Bradley-Terry 模型四维评分（必备技能 + 加分技能 + 经验 + 学历）。权重经 `tune_match_weights_fourdim.py` 在 384 对金标上网格搜索确定。v4 引入 education 维度（w\_edu=0.15）后 Acc 由 v3 三维基线的 **0.9141** 提升至 **0.9714**（+5.7pp），Spearman ρ 0.7407→**0.7853**（与设计文档 §9.4 BT 四维重调表一致）。

> 2026-09-04 勘误：原稿"技能 + 经验 + 学历 + 岗位域"维度表述有误——岗位域为领域语义黑名单过滤（`domain_sem_blocklist.json`），不参与评分加权；原稿"v3 的 0.96"系 v1 金标 Acc 0.9600 误植，v3 三维基线为 0.9141（384 对 v3 金标实测，`configs/match_weights.json` 注释同步）。

> v1（0.96）与 v2（0.8906）口径均已弃用，**对外主口径 = BT v4 0.9714**。

### 2.3 标注模式如实说明

黄金集 110 条 JD 由 A01 单人标注 + QA 审核完成（Round1, PR #316）。**非双人独立标注，未计算 Cohen's Kappa**。标注质量经多轮盲审（round2/round3）复核维持。
