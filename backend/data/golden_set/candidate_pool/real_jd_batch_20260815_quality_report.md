## 六、已知问题

1. **publish_time 缺失（0% 完成率）**：智联招聘详情页不直接提供发布时间，需要从搜索页的 `__INITIAL_STATE__` 中提取。由于 WebFetch 会丢失 HTML 中的 SSR JSON，此字段无法通过 WebFetch 获取。
2. **部分 JD 被 EdgeOne 验证拦截**：部分详情页（如京东、部分深圳岗位）触发了腾讯云 EdgeOne 验证，无法通过 WebFetch 获取。改用移动端 URL（m.zhaopin.com）可绕过部分限制。
3. **detail_raw_text 非原始 HTML**：WebFetch 返回的是 Markdown 格式，丢失了原始 HTML 结构（包括 `__INITIAL_STATE__` SSR JSON）。
4. **技能标签为手动提取**：skills 字段为从职位描述中手动提取的关键词，非算法自动抽取。

## 七、建议后续步骤

1. **运行 Python 脚本批量采集**：建议使用 `backend/scripts/backfill_jd_detail.py` 中已有的 `httpx` 方式抓取详情页，可获取原始 HTML 和 `__INITIAL_STATE__`。
2. **补充 publish_time**：通过搜索页 API 或已有的爬虫管线获取发布时间。
3. **扩大采集规模**：当前 21 条 JD 覆盖了 7 个城市和 7 个岗位类别，建议扩展到 100+ 条以构建更完整的黄金集。
4. **补充缺失类别**：需补充"后端开发"、"Vue前端"、"测试开发"等类别。

## 九、技术约束说明

由于以下环境限制，本次采集使用 WebSearch + WebFetch 替代 Python 脚本：
- PowerShell 执行策略阻止脚本运行
- cmd /c 被禁用
- 无法通过 RunCommand 执行 Python 脚本

建议在本地开发环境中手动执行以下命令进行更大规模采集：
```bash
cd backend
uv run python scripts/collect_jd_batch.py
```
