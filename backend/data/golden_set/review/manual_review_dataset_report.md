# 正式人工复核候选集报告

## 结论

本轮形成 **12 条**可用于人工六字段标注的 JD 候选，而不是强行补成 20 条。每条均满足：可追溯 `source_url`、非空的真实详情页 `detail_raw_text`、中文国内岗位、包含岗位职责和任职要求、且与表中其他条目不重复。

其余 8 条原智联候选在普通公开访问下未能取得正文；本轮不使用字段拼接摘要、AI 改写文本或平台访问限制规避方式补齐它们。因此没有把它们收入正式候选表。

## 信息不足与使用边界

12 条入选样本均具备启动人工标注的最小证据条件；没有因正文不足而被纳入的样本。

部分公开详情页可能标注为已失效，这不影响已公开读取到的原始 JD 正文作为本轮人工复核证据，但不应被解释为仍在招聘。`detail_raw_text` 仅保存详情页的岗位职责和任职要求原文，不用列表/API 元数据替代正文。

`jd_manual_review_20.csv` 的所有 `review_*`、`review_status`、`error_type`、`review_note` 均保持为空。10 条新增样本的 `current_gold_*` 也全部留空；本轮没有生成任何黄金标签。

## 是否具备开始人工标注的条件

**具备。** 可立即对这 12 条开展人工六字段复核。若必须达到 20 条，应在后续以同样的公开正文与可追溯 URL 门槛继续补充 8 条；不要重新启用缺少正文的旧 BOSS 或旧智联摘要样本。
