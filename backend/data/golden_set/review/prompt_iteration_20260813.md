## 触发

合并盲审（round1 12 条人工 gold + round2 20 条 AI gold，32 条）title 失配 15/32，根因两类：

1. **gold 口径（终审确定）vs LLM 行为冲突**：gold 按招聘标题语义 + 保留技术栈细化前缀（React/Vue/Golang/SLAM）；LLM 按正文主导技术/职责推断岗位名
   - public_001 标题"python开发工程师"、正文 Odoo 出现 5 次 → LLM 输出"Odoo开发工程师"（规则 1 产品名排除失效）
   - r2_017 标题"AI全栈工程师"、正文职责以客户端为主 → "客户端开发工程师"
   - r2_018 标题"Python工程师"、正文量化金融 → "计算金融软件工程师"
   - r2_011 标题"slam算法工程师" → 泛化"机器人系统工程师"
2. **细化前缀丢失**：React前端/Vue前端 → 统一泛化"前端开发工程师"

- **React/Vue/SLAM 前缀保留仍失败**（r2_001/014/015/011）：LLM 泛化惯性 + 跨运行不稳定（r2_011 在 1939 复现"机器人系统工程师"）——title 维度受模型波动影响大于 prompt 可调空间，追平边际收益低
